# Cube Wrangler

Cube Wrangler provides utilities for bridging [Network Wrangler](https://network-wrangler.github.io/network_wrangler/) with [Bentley Cube](https://www.bentley.com/software/cube/) travel modeling software.

**Key capabilities:**
- Export Network Wrangler networks to Cube roadway format
- Export transit networks to Cube `.lin` format
- Convert Cube Log files to Project Cards
- Diff two Cube `.lin` files into a Project Card

## Requirements

Python 3.10+

## Installation

```bash
# Recommended
uv add cube-wrangler

# pip
pip install cube-wrangler
```

### From source

```bash
git clone https://github.com/network-wrangler/cube_wrangler
cd cube_wrangler
uv sync
```
